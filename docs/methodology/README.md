# Research Methodology

STYX-LAB follows a repeatable security-testing workflow.

## 1. Identify

Determine the expected security control and the observable condition that indicates a problem.

## 2. Validate

Confirm the behavior in the controlled laboratory without relying on assumptions.

## 3. Understand

Record the security impact, prerequisites, affected component, and relevant defensive controls.

## 4. Remediate

Apply a defensive configuration or code change appropriate to the scenario.

## 5. Re-test

Repeat the same validation after remediation and record the result.
