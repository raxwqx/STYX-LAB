# Research Methodology

STYX-LAB aims to make each learning exercise reproducible and evidence-based.

1. **Define:** State the objective, scope, prerequisites, and expected secure behavior.
2. **Observe:** Record status codes, response headers, outputs, and environment details.
3. **Validate:** Compare observations against explicit criteria; do not infer success.
4. **Assess:** Explain defensive relevance and limitations without overstating impact.
5. **Remediate:** Apply a suitable configuration or code change.
6. **Re-test:** Repeat the original check and retain the evidence.
7. **Report:** Generate JSON and Markdown records for local training results.

All provided services bind to IPv4 loopback. Never test systems without authorization.
