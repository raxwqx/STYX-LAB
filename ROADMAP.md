# Roadmap

This roadmap describes possible follow-up work, not currently implemented features.

## v1.0.1 baseline

- [x] Local-only HTTP security headers lab
- [x] Baseline and secure profiles
- [x] STYX-LAB / STYHQ terminal control deck with lock-opening startup animation
- [x] JSON and Markdown evidence reports
- [x] Automated tests and CI workflow

## Future candidates

- [ ] Add another self-contained web defensive scenario with dedicated tests
- [ ] Add optional report metadata supplied by the user
- [ ] Improve accessibility and terminal-width behavior
- [ ] Publish example reports produced by the test suite

Features should be added only when they have explicit acceptance criteria,
repeatable steps, a clear scope, and tests where practical.
