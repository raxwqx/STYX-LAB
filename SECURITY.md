# Security Policy

STYX-LAB is educational software. Its lab server intentionally binds to
`127.0.0.1` and is not designed for public deployment.

## Repository vulnerabilities

Use GitHub's private vulnerability reporting feature if enabled. Otherwise,
contact the maintainer privately where possible. Avoid publishing sensitive
or exploitable details in public issues before coordinated remediation.

## Scope

This policy covers the repository and the supplied training code. It does
not authorize testing third-party systems. Obtain explicit permission before
security testing outside a controlled environment you own or administer.
